Rain Island：用 Three.js 复现雨天的 3D 降水场景

2026/10/4 项目记录 Three.js WebGL JavaScript 可视化

Rain Island 是我做的一个 Windows 降雨提醒项目。我想把天气预报中的数字变成能直接看懂的画面：雨从什么时候开始、雨势如何增强、又怎样逐渐减弱，都可以在一段三维雨景里看到。

这篇文章记录其中最主要的部分——用 Three.js 和 GLSL 复现雨天的降水场景。下面的图片和交互预览均来自项目原始渲染代码，使用模拟降水数据。

# 实际 3D 预览

可以切换小雨、中雨、大雨，拖动时间轴观察同一场雨的强弱变化，也可以点击“环绕镜头”从不同方向观看。点击“播放过程”，会用约 15 秒播放完整的模拟降雨过程。

预览只在浏览器本地运行，不查询真实天气，不请求定位。页面不包含实际地点、经纬度、个人天气接口地址、密钥或观测记录。

# 桌面项目介绍

桌面版使用 Electron 承载透明置顶窗口，以胶囊展开的方式显示雨景、降水时间轴和提醒信息。Three.js 负责三维场景，GLSL 着色器负责雨丝下落、涟漪扩散以及水滴弹起的动画。雨声则是另一个独立模块，桌面版支持程序合成雨声与自选录音。

这次博客展示只提取雨景渲染层。原项目的桌面窗口、天气服务连接、设置存储和雨声模块没有打包进网页，访客无需安装桌面程序即可查看模型效果。

这里的“3D 模型”是通过代码生成的场景：没有加载现成的雨景模型文件，也没有用 GIF 或视频代替三维渲染。雨丝是线段，涟漪是实例化平面，弹起的水滴是点精灵，透视相机提供空间深度。

# 场景怎样组成

场景层 实现方式 主要作用
雨丝 BufferGeometry + LineSegments 在空间中生成下落线段
湿润地面 平面 + 自定义片元着色器 表现受光区域与细碎水面高光
落地涟漪 InstancedBufferGeometry 批量生成不同位置、不同生命周期的扩散圆环
弹起水滴 Points + 点精灵着色器 增加雨点落地后的细节
透视镜头 PerspectiveCamera 产生远近关系，并实现真正的镜头环绕

默认上限是 6,000 条雨丝、2,300 个涟漪实例和 1,800 个弹起水滴。实际显示数量随雨势调整。它们是视觉效果参数，不对应真实世界某一平方米内的雨滴数量。

# 核心代码：让降水强度驱动画面

# 1. 从 mm/h 映射到视觉强度

渲染层接收降水强度 rate，单位为 mm/h，再把它映射为 0～1 的视觉强度。非线性映射让小雨也有可见细节；随后用指数平滑避免雨势切换时画面突然跳变。

// RainScene.setRate(rate)
this.target = Math.min(1, Math.pow(Math.max(0, rate) / 16, .6));

// RainScene.render(dt)，dt 的单位是秒
this.intensity += (this.target - this.intensity)
  * (1 - Math.exp(-dt * 5));

this.uniforms.uIntensity.value = this.intensity;
this.rain.geometry.setDrawRange(0, Math.round(this.intensity * 6000) * 2);
this.splashes.geometry.instanceCount = Math.round(this.intensity * 2300);
this.spray.geometry.setDrawRange(0, Math.round(this.intensity * 1800));

每条雨丝有两个顶点，因此雨丝的绘制顶点数需要乘以 2。涟漪和弹起水滴也使用同一个强度参数，保持场景整体一致。

如果输入是五分钟累计降水量，换算到五分钟平均强度的关系是 rate = amount × 60 / 5 = amount × 12。这两种单位必须区分：累计量是 mm，强度是 mm/h。

# 2. 在 GPU 上计算雨丝下落

雨丝初始位置在 JavaScript 中一次性生成，每帧只更新时间等 uniform。下面节选自原始顶点着色器：

vec3 p = position;
float speed = 8.5 + seed * 5.;
p.y = mod(position.y - uTime * speed, 13.);
p.x += p.y * .035;

vec4 mv = modelViewMatrix * vec4(p, 1.);
gl_Position = projectionMatrix * mv;

seed 给不同雨丝分配速度，mod 使雨丝落到底部后回到上方，轻微的横向偏移形成倾斜。相机矩阵再把三维坐标投影到屏幕，远近雨丝因此有不同的空间表现。

# 3. 用实例化平面生成落地涟漪

大量涟漪共用同一份平面几何体，每个实例只保存落点 offset 和相位 phase。顶点着色器决定扩散大小，片元着色器画出环形亮度并让它逐渐消失。

// 顶点着色器节选：扩散生命周期
vLife = fract(uTime * (1.25 + phase * .8) + phase * 19.);
float scale = .1 + vLife * .85;
vec3 p = offset + vec3(position.x * scale, 0.015, position.y * scale);

// 片元着色器节选：环形高光与淡出
float d = length((vUv - .5) * 2.);
float aa = max(.045, fwidth(d) * 1.2);
float ring = exp(-pow((d - .76) / aa, 2.));
float center = exp(-d * d * 45.) * exp(-vLife * 15.);
float a = (ring * .85 + center * 1.3)
  * pow(1. - vLife, 1.5) * vLight * (.35 + uIntensity * .65);

不同相位让各个涟漪错开出现。圆环所在平面贴近地面，透视投影后呈现椭圆形，而不是在屏幕上直接画一圈二维圆形。

# 4. 让镜头真正环绕场景

原项目展开时会用约 1.6 秒环绕一周，再回到原视角。它改变的是相机位置，博客预览中的“环绕镜头”也复用了同一逻辑。

const p = this.orbitElapsed / this.orbitDuration;
this.orbitAngle = p >= 1
  ? Math.PI * 2
  : Math.PI * 2 * p * p * (3 - 2 * p);

this.camera.position.set(
  Math.sin(this.orbitAngle) * 13.9,
  5.1 + Math.sin(Math.PI * p) * .45,
  -1.5 + Math.cos(this.orbitAngle) * 13.9
);
this.camera.lookAt(0, .8, -1.5);

# 效果与边界

这个项目主要探索“怎样把降水强度表达得更直观”。它采用程序化雨景和风格化水面高光，弹起水滴使用正弦轨迹，不是完整的流体、碰撞或物理光照模拟。画面还原的是雨的视觉感受，不能从画面反推出精确降水量。

小 / 中 / 大的视觉档位以 2.5 和 7.5 mm/h 分界，不等同于气象部门按累计雨量划分的小雨、中雨、大雨等级。博客里的时间全部是相对演示分钟，数据全部为模拟，没有地点对应关系，也不代表真实天气预测准确率。

后续可以继续改善地面材质、水滴运动和不同雨势之间的层次，让雨景更自然。完整渲染代码已附在上方，本文的片段用于解释各个层次如何协作。
