# Observatory fonts

Ma Shan Zheng and Noto Serif SC are distributed under SIL Open Font License. The adjacent OFL files retain their licenses.

These small TrueType subsets were obtained from the Google Fonts CSS API on 2026-10-23. The active Ma Shan Zheng file, observatory-poetry.ttf, includes every character in the two user-provided poems beginning 往事越千年 and 林花谢了春红, the author signature 南风知我意, and the music phrase 把这一刻留给音乐. The earlier observatory-hand.ttf is the original signature-only subset. Noto Serif SC contains the site's brand and navigation characters. Other text uses platform serif/sans-serif fallbacks. If the text-flow copy changes, request an updated subset including those glyphs; do not distribute Windows KaiTi/SimSun font files.

Official source: https://github.com/google/fonts/tree/main/ofl/mashanzheng and https://github.com/google/fonts/tree/main/ofl/notoserifsc
